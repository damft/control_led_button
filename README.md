# Control LED Button

## Deskripsi

Project Arduino Uno untuk mengontrol LED menggunakan push button. Project ini terdiri dari tiga pengembangan, yaitu kontrol 1 LED, 2 LED, dan 3 LED menggunakan button.

## Project

1. Control 1 LED menggunakan 1 Button.
2. Control 2 LED menggunakan 2 Button.
3. Control 3 LED menggunakan 3 Button.

## Hardware

- Arduino Uno
- LED
- Push Button
- Resistor 220 Ohm
- Breadboard
- Jumper Wire

## Pin Configuration

### Control 1 LED

- LED: D8
- Button: D2

### Control 2 LED

- LED 1: D8
- LED 2: D9
- Button 1: D2
- Button 2: D3

### Control 3 LED

- LED 1: D8
- LED 2: D9
- LED 3: D10
- Button 1: D2
- Button 2: D3
- Button 3: D4

## Cara Kerja

Setiap button mengontrol LED masing-masing. Ketika tombol ditekan, LED menyala. Ketika tombol dilepas, LED mati.
